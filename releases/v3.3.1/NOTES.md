# ddns-go-android-root 3.3.1

Magisk、KernelSU/BakaSU、APatch BusyBox 自动识别；升级自动更新后台组件，保留域名、Token、间隔及唤醒锁设置。

Detect Magisk, KernelSU/BakaSU and APatch BusyBox automatically. Upgrade bundled controls while preserving DNS credentials, intervals and wake-lock choices.

首次使用需本人确认 Root、Shizuku 和系统权限，并在手机本地配置账号。详见 NEW-PHONE-SETUP.md。没有上传私人配置或签名密钥。

First use requires user-approved permissions and local account setup. No private configuration or signing key is included.
